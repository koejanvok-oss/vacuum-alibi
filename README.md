## The line

> That corner is a scheduled no-go zone: my sensors classified it as haunted, and my battery does not cover exorcisms.

One original line (116 characters) in which a robot vacuum explains why it missed a spot — deadpan, a little smug about its schedule, its sensors and its battery, with the punch at the end.

## Usage

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
